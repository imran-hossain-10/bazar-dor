# BazarDor

## Project Description

BazarDor is a web application that helps users check the prices of daily essential products in Bangladesh.

Users can explore different product categories, check current market prices, compare prices across markets, and track price changes.

The application provides a simple and responsive interface for mobile, tablet, and desktop users.

## Technologies Used

- Next.js
- React.js
- TypeScript
- Tailwind CSS
- MongoDB
- Better Auth
- Lucide React
- React Hot Toast
- REST API

## Main Features

### 1. Daily Product Prices

Users can view the latest available prices of daily essential products such as rice, lentils, oil, vegetables, fish, meat, and eggs.

### 2. Product Categories

Products are organized into different categories. Users can browse products based on their categories.

### 3. Product Details

Each product has a details page where users can view product information, current prices, previous prices, and available market data.

### 4. Price Increase Tracking

The application displays products whose prices have increased compared to the previous day.

### 5. Price Decrease Tracking

Users can easily identify products whose prices have decreased.

### 6. Market Price Comparison

Users can compare the prices of products across different markets and view minimum and maximum prices.

### 7. User Authentication

Users can register, log in, and log out securely using Better Auth.

### 8. User Profile

Logged-in users can access their profile page to view their name, email address, profile picture, and account information.

### 9. Responsive Design

The website is responsive and works on mobile phones, tablets, and desktop computers.

### 10. Bengali Language Support

The application displays product names, categories, prices, and dates in Bengali.

### 11. Price Ticker

A price ticker displays product price information to help users stay updated.

### 12. Loading and Error Handling

The application includes loading skeletons, error messages, retry options, and toast notifications.

## API Information

BazarDor uses the Programming Hero API to fetch product and category information.

Primary API:
https://openapi.programming-hero.com/api/bazardor

Available API Endpoints:

All Products: /products

Category Filter: /products?category=chal

Single Product: /products/1

All Categories: /categories

Single Category: /categories/chal
## Installation and Setup

Step 1: Clone the GitHub repository.

Step 2: Open the project folder.

Step 3: Install the required dependencies using npm install.

Step 4: Create a .env.local file and configure the required environment variables.

Step 5: Start the development server using npm run dev.

Step 6: Open the application in your browser.

## Authentication

The application uses Better Auth for authentication and MongoDB for storing user authentication data.

Users can create accounts, sign in, access their profiles, and sign out.

## Project Purpose

The main purpose of BazarDor is to make daily market price information easily accessible to people in Bangladesh.

The platform helps users understand product price changes and compare prices across different markets.
